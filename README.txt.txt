# Smart Recipe Finder

## Project Description
Smart Recipe Finder is a web application that helps users explore recipes and find recipes based on selected ingredients.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Main Features
- Browse recipes by category
- Search for recipes
- View recipe ingredients and preparation details
- Find recipes using selected ingredients
- Navigate between recipe pages and category pages

## Database
Database Name: smart_recipe_finder_v2

Database Backup: smart_recipe_finder_v2_backup.sql

## How to Run
1. Install Node.js and MySQL.
2. Import the database backup into MySQL.
3. Configure the backend environment variables in the `.env` file.
4. Open a terminal in the backend folder.
5. Run `npm install`.
6. Run `npm start`.
7. Open the frontend HTML page in a browser.

## Project Purpose
This project demonstrates recipe browsing, ingredient-based recipe matching, and database integration in a web application.
